# Data pipeline

Private workflow project for role-based data collection and enrichment.

Includes the 79-role catalog and six-keyword workflows, direct state-by-state execution, automatic checkpoint recovery, full descriptions, and all-jobs/strict-title Excel exports. See dashboard/linkedin/TASK_RECOVERY.md for resuming runs.

Only tracked source and tests are included; no environment files, credentials, collected datasets, or previous Git history are copied. Platform-side H-1B filters remain in the application repository.
